# Proyecto JavaScript + MySQL

1. Asegúrate de que la base de datos `software` ya exista.
2. Ejecuta `crear_tabla.sql` dentro de esa base.
3. Abre una terminal en esta carpeta.
4. Ejecuta:
   npm install
5. Luego:
   npm start
6. Abre:
   http://localhost:3000
7. Para probar solo la conexión:
   http://localhost:3000/probar-conexion

La conexión a MySQL está en `db.js`.
